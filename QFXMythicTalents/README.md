# QFX Talent Recommendations 0.7.3

## 0.7.3 EUI 主题下的选中效果

- EUI 皮肤激活时，推荐列表与“我的方案”列表的选中高亮改用 EUI 的用户强调色（accent）：左侧 3px 强调竖条 + 低透明度同色填充，与 EUI 内部的选中语言一致。
- 选中颜色通过 EUI 官方 `GetAccentColor` / `OnLooksChanged` 接口读取并实时跟随用户在 EUI 中修改的强调色，不写入任何 EUI 设置。
- “我的方案”的选中行新增同款左侧强调竖条；未使用 EUI 时保持原有蓝色/金色高亮不变。

## 0.7.2 性能清理与死代码删除

- 面板状态行（样本数、状态、数据库版本）只在内容变化时写入，避免每次刷新做无意义的字体布局计算。
- 推荐列表与“我的方案”列表的行按钮改为每行只安装一次点击/悬停脚本，重建列表不再为每个条目分配闭包。
- “我的方案”的战斗/专精/天赋变更事件改为仅在面板可见时注册，面板关闭后不再监听任何事件（除等待 TalentLoadoutsEx 加载）。
- 删除未使用的界面文案（“导入推荐”“数据来源”）、无引用的导出接口与残留变量；EUI 皮肤桥接只保留实际用到的原语，暂无新增功能。

## 0.7.1 应用推荐不再累积天赋配置

- “应用推荐”现在会清理当前专精下历史遗留的自动生成配置（名称以 `QFX_` 开头的推荐配置），并在导入完成后再次清理，天赋配置列表中始终只保留一个自动生成配置。
- 当前正在使用或最近选择的配置不会被删除；其它非 `QFX_` 开头的配置（包括“我的方案”里的个人方案在暴雪配置表中的条目）不受影响。
- 导入失败、或客户端没有生成新配置时不做清理；清理只作用于当前专精，战斗中的延迟应用行为不变。

## 0.7.0 EllesmereUI 皮肤支持

- 安装并启用 EllesmereUI 时，天赋推荐侧栏自动套用 EUI 当前窗口皮肤（含 Modern 扁平风格），按钮、关闭按钮、滚动条与标题文字一并跟随 EUI 主题和实时配色；未安装或未启用皮肤时保持原有外观，功能不变。
- 皮肤通过 EUI 官方 `EllesmereUI.RegisterSkin` 接口注册，随 EUI 主题切换实时更新，不写入任何 EUI 设置。
- 列表行内的自绘内容（选中高亮、方案图标、"已加载"标记）改挂在按钮之上的覆盖子框架中，天赋窗口重建时 EUI 重新铺贴皮肤不会把这些元素一并淡化。
- 本地化与数据库格式不变；TOC 增加可选依赖 `EllesmereUI`。

## 0.6.6 清理与性能优化

- 完全移除旧的逐节点退款、购买、英雄树重置与结果校验回退；应用推荐现在只使用暴雪原生整串导入，失败时不会再尝试局部修改天赋。
- 保存个人方案也只使用暴雪原生整串导出，删除重复维护的手工序列化路径。
- 移除初始天赋方案重试状态、无用事件监听和仅供旧回退使用的提示文本。
- 个人方案应用后不再额外定时导出与重建；统一由已有的天赋配置事件防抖刷新，减少一次重复遍历和界面重绘。
- 旧版数据库解码与注册接口仍保留，用于兼容已经发布的数据包。

## 0.6.5 修复

- 未选择的二选一节点优先显示推荐选项的使用率，不再被暴雪当前展示的 `0%` 默认选项遮蔽。
- 节点没有推荐状态时，显示两个选项中较高的使用率；只有两个选项都为 `0%` 时才隐藏百分比。
- 悬浮提示同步显示本次百分比实际对应的天赋名称。

## 0.6.4 修复

- “应用推荐”改为优先调用暴雪原生整套天赋导入流程，不再自行逐节点退款和购买，避免旧节点退款失败后占用点数，造成推荐中的 `100%` 节点无法选中。
- 暴雪导入接口不可用时才使用兼容性逐节点应用；兼容路径改为从树底向上退款并增加依赖重试次数。
- 团本、大秘境推荐和“我的方案”都会把方案名称一并交给暴雪导入器。

## 0.6.3 发布

- 已对发布源码与游戏内安装副本进行逐文件 SHA-256 校验，`0.6.2` 内容完全一致。
- 所有 Lua 源文件通过 `luac -p` 语法检查，未发现新的阻断性问题。
- 递增补丁版本号并重新打包发布。

## 0.6.2 修复

- 个人方案空列表时不再显示不可拖动的滚动条；只有内容超出可视区域时才显示。
- 主推荐列表滚动条补齐锚点，会随自适应高度一起移动/缩放。
- 保存方案改为优先调用暴雪原生 `GetLoadoutExportString()`，并保留兼容回退。
- 修复 StaticPopup 将 `text` 写成函数导致的保存/重命名弹窗报错。
- 保存失败时捕获错误，不再直接中断 Lua，并在聊天框输出具体失败原因。

## 0.6.1 修复

- 右侧面板高度改为实时跟随暴雪天赋窗口，并按当前窗口高度自适应“我的方案”区域，避免小尺寸/缩放下侧栏超出天赋页。
- 修复新版 StaticPopup 编辑框字段名变化导致“保存/重命名”无法读取方案名称的问题；保存仍直接导出当前专精的当前天赋。
- 地下城名称优先读取客户端 `C_ChallengeMode.GetMapUIInfo`，数据库本地化同时增加按副本数字 ID 回退，简体/繁体客户端不再因赛季 slug 变化退回英文。
- 数据采集工作流不再写死旧团本 WCL zone，改为发现当前活动团本并映射 Warcraft Logs zone；当前赛季清单已更新为潮缚石窟与烈毒之渊。

## 0.6.0 一键应用与本地方案

- 合并 TalentLoadoutsEx 式方案管理：天赋页右侧面板加宽为 200px 全高，上半部分保持副本/首领推荐与节点百分比，下半部分新增"我的方案"列表。
- "导入推荐"改为"应用推荐"：不再打开暴雪导入窗口，直接通过 `C_Traits` 节点 API 写入天赋树并自动提交；战斗中自动延迟到脱战，观察他人时禁用，直接应用失败时回退到暴雪原生导入窗口。
- 应用引擎完整处理英雄天赋子树切换（`ResetTreeByCurrency`）、顶点多等级节点、初始天赋方案（Starter Build）与多轮依赖购买。
- 副本/首领列表改为固定高度的滚动列表，放不下时出现滚动条，并自动把当前选中项滚动到可见范围。
- 个人方案按专精保存于 `QFXMythicTalentsDB.loadouts`，支持保存/载入/重命名/删除/上移/下移，列表显示当前已加载的 ✓ 标记。
- 检测到原版 TalentLoadoutsEx 时自动隐藏本地方案列表并将面板让位到其右侧，避免重叠。
- 数据库格式与采集管线完全不变；UI 上用户只看到节点百分比，推荐字符串仅在后台用于应用。

## 0.5.0 正式版

- 显示插件正式名称为“群飞轩天赋推荐”，面板底部显示插件版本和数据库日期。
- 数据库拆分为基础清单、大秘境、英雄团本、史诗团本四个目录；后三者按需加载，未查看的内容类型不进入内存。受 WoW 插件机制限制，已经查看并加载的子插件会保留到下次重载界面。
- 10 份样本在数据库生成阶段直接转换为紧凑节点统计，游戏内切换副本或首领时不再解析任何样本天赋字符串。
- 推荐天赋字符串仅作为原生导入窗口的输入；只有用户点击“导入”时才从紧凑字符串块中取出。
- 玩家当前天赋直接通过 `C_Traits` 节点 API 读取并缓存，切换副本或首领时复用，不再生成和反解析当前天赋字符串。
- 导入、确认、Spinner、遮罩和动画全部交给暴雪原生界面；插件只在配置事件安静 0.35 秒后合并刷新一次。
- 修复多级顶点天赋的运行时条目与导入字符串条目不一致时误显示 `0%` 的问题。
- 观察其他玩家或打开天赋链接时，推荐会自动切换到被查看的职业与专精；退出观察后恢复自己的专精推荐。
- 右上角 X 仅在当前登录会话彻底停止插件；重新载入或登录后自动启动。导入按钮下方可独立关闭或恢复节点百分比显示。

## 0.4.6 快速切换 CPU 与内存优化

- 10 份样本只用于计算节点选择率，不决定实际导入内容；导入仍只使用当前专精、当前副本或首领的一条推荐。
- 副本、首领或难度快速切换增加 0.18 秒防抖，只有最后停留的选项会启动样本解析。
- 样本改为每帧只解析一份，取消选项后旧任务立即失效，避免单帧创建大量临时表。
- 移除最近 3 个选项的统计缓存，内存中只保留当前最终选项的统计结果。
- 每份样本处理后增量回收临时对象，降低连续切换时的内存峰值。

## 0.4.5 选择操作 CPU 优化

- 普通天赋节点选择不再被当作专精切换，不再重复解析 10 份推荐样本。
- 缓存玩家当前天赋导出字符串，相同事件风暴不再重复解码和装饰整棵天赋树。
- 同一配置复用天赋条目到节点的映射，避免切换副本时重复扫描树结构。
- 最近 3 个副本或首领统计使用有界缓存，切回时直接复用；专精切换或关闭界面时统一释放。
- 移除每次选择副本或首领时主动推进垃圾回收的 CPU 开销。

## 0.4.4 单数据库紧凑加载

- 40 个专精重新合并到一个 `QFXTalentData` 插件，插件列表不再出现大量专精子插件。
- 所有专精仅以紧凑加载器形式注册，只有当前专精会展开为可查询的数据表。
- 继续支持专精切换、切回重建、关闭界面释放，以及当前副本/首领解码缓存释放。
- 相比完全按专精子插件加载会多保留约 1 MB 紧凑加载器，但仍远低于旧版约 20 MB 的完整表结构。

## 0.4.3 专精级按需加载

- 数据库拆分为 40 个专精子插件，只载入玩家当前专精，不再执行其他职业或同职业其他专精的数据文件。
- 切换专精时释放旧专精的实体数据；切回时由对应专精加载器重新构建。
- 关闭天赋界面后释放当前专精实体数据，重新打开时再按需恢复。
- 副本或首领切换时只保留当前选择的解码统计，上一份统计立即解除引用并推进垃圾回收。
- 数据日期独立显示为短日期，并与状态文字、导入按钮分行，避免互相遮挡。

## 0.4.2 界面与内存优化

- 侧栏加宽并压缩列表行距，团本首领列表与底部样本信息不再重叠。
- 选中状态改为短暂淡入、左侧高亮和细边框，不再锁定暴雪按钮高亮效果。
- 地下城、团本和难度切换复用固定按钮池，避免反复创建 Frame 导致内存持续增长。
- `QFXTalentData` 改为打开天赋界面时按需加载，未使用功能时不再常驻大型数据库。
- 当前职业载入后释放本插件不使用的预计算选择率表，保留原始样本与推荐功能。

在暴雪原生天赋界面显示大秘境和团本首领天赋推荐，需要独立数据库 `QFXTalentData`。

- 团本页按首领显示推荐天赋。

- 进入英雄或史诗团本时自动识别当前难度。

- 当前首领、专精或难度暂无数据时显示“暂无数据”，不会沿用上一个首领的百分比，也不会用英雄数据代替史诗数据。

## 大秘境功能保留

- 自动识别当前大秘境。
- 在天赋节点旁显示 10 份样本的选择率。
- 显示当前天赋是否与推荐一致。
- 一键打开暴雪原生天赋导入窗口。

## 数据库

使用数据库基础插件及三个按需加载内容插件：

```text
QFXTalentData
QFXTalentData_MythicPlus
QFXTalentData_RaidHeroic
QFXTalentData_RaidMythic
```

数据库内容包括：

- 全球大秘境：副本 × 专精推荐。
- 全球团本：首领 × 专精 × 英雄/史诗推荐。
- 每组一份推荐导入字符串及由 10 份样本预计算的紧凑节点统计。

旧的 `QFXMythicTalents_Data` 只保留大秘境兼容，不提供新的英雄/史诗团本数据。
